# Start here — NexusForge 3.0

1. Review `presentation/NexusForge-Pitch.pdf` (six slides).
2. Open `NexusForge-demo.html` offline, or run `npm start` with Node.js 24+ and visit `http://localhost:8000`. No dependencies to install.
3. **Evidence studio → The €18.50 question → Counterfactual lab**. Choose **Leak independently confirmed**, change stock to **0**, then restore **15**. The recommendation changes.
4. Read `docs/DEMO_PLAYBOOK.md` for speaker notes and the 90-second flow.
5. Run `npm test`, `npm run evaluate`, then `npm run verify:live` on the connected laptop. `docs/INTEGRATIONS.md` explains missing real Evolus workspace configuration.
6. Read `docs/SUBMISSION.md`. Real AMD usage remains an eligibility blocker until demonstrated; Evolus prize requirements are stricter.

**Received a mail-safe ZIP?** Follow its `OPEN_THIS_FIRST.txt`, rename `RESTORE.cjs.txt` to `RESTORE.cjs`, and run `node RESTORE.cjs`. Private credentials decrypt locally with the separately delivered passphrase. They are not needed for the offline demo.

Do not publish the private archive, `.env`, passphrase or original ZIP. Rotate the shared keys after transfer.
