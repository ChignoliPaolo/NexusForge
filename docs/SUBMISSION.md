# Submission kit and remaining gates

## Ready-to-use project details

**Title:** NexusForge — Change the outcome

**Challenge:** Intelligent Industry

**Short description:** An evidence-first industrial decision twin that challenges fault hypotheses, selects the next informative observation, compares only feasible recovery actions, and keeps a human accountable. Change the evidence or remove a part: the decision changes.

**Long description:** Factory alarms identify a symptom, not necessarily the right intervention. NexusForge helps a line supervisor move from sensor observations and engineering context to a reviewed action. A validated CSV/reference intake makes inputs inspectable; explicit hypothesis weights and assumed test likelihoods select an informative follow-up observation. An independent solver checks parts, deadlines, contradictory signals and safety holds before comparing numerical costs. An AMD-hosted model can review the evidence and cite sources without overriding constraints or approving work. Evolus adapters retrieve knowledge, validate extracted planning fields and request a workflow only after human acknowledgement. The prototype includes eight clearly synthetic challenge cases, an interactive procedural factory, evidence/decision exports, reproducible checks and an offline fallback. Modeled costs are not realized savings; scores are not calibrated probabilities. Real sponsor usage must be demonstrated with actual receipts and workspace configuration.

## Data and visual provenance

All eight CSVs and the engineering handbook are authored synthetic fixtures generated by `server/samples.mjs`. They are not real production measurements or manufacturer procedures. Twelve additional seeded perturbations test declared contracts; they are not an independent benchmark. No downloaded industrial dataset or external OEM document is represented as ours.

Factory geometry, charts, icons and slide layouts are generated from repository code. The PDF uses locally available fonts and includes an accessible Markdown transcript. There are no raster stock photographs or borrowed logos in the deck. The exported cover and slides do not prove live service operation.

The original project ZIP is preserved unchanged outside the source folder and must remain private.
